Every model goes through the same pipeline; only the cell changes. We classify from the state after the last real token, not from pooling, so the decision depends on what the cell remembers. The protocol is identical for every model: same splits, same loss, same optimiser, early stopping on validation macro-F1, and each architecture is trained with three seeds so we can report a mean and a standard deviation. To be sure our cells are correct, we unit-tested them against PyTorch’s own LSTM, used only as a reference. One engineering note: slicing x[:, t] inside the loop made the backward pass quadratic in length; using unbind made training five times faster.

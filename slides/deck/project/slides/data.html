Without cleaning, test scores would reward memorisation · 03

Our first finding came from the exploratory analysis. Thirty percent of the training reviews are exact copies: the same review is listed under the brand name and the generic name of the same drug, with the same rating in 99.9 % of cases. Worse, 60 % of the official test reviews appear word for word in the training set. A model could score well by memorising. So we keep one copy of each review and remove from the test set everything seen in training. We end with about 101k training, 11k validation and 16k test reviews, with the same class proportions in all three.

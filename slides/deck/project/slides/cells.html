Modelling approach

Four cells, all built from nn.Linear

Vanilla LSTM · baseline

Input, forget and output gates around a memory cell

c_t = f_t*c_{t-1} + i_t*g_t

394k recurrent parameters (H = 256)

WMC · working memory

The gates also read the memory cell

i_t = σ(… + tanh(W_ci c_{t-1}))

591k parameters (+3 H×H matrices)

CIFG · coupled gates

What is written is exactly what is forgotten

i_t = 1 - f_t

296k parameters (one gate fewer, −25 %)

LSTMP · projection

H memory cells, but a smaller output of size P

h_t = W_p m_t + b_p

296k parameters (H = 256, P = 128)

Landi et al. 2021 (WMC) · Greff et al. 2017 (CIFG) · Sak et al. 2014 (LSTMP) · 05

All four cells are written from scratch. For each cell, the gate matrices acting on the input are stored side by side in one nn.Linear, and those acting on the hidden state in another: same equations, one matrix product. WMC adds three matrices so that the gates can look at the memory cell itself; it is the biggest model. CIFG removes the input gate: it is one minus the forget gate. LSTMP keeps 256 memory cells but only feeds back a 128-dimensional projection. Note that CIFG and LSTMP end up with almost exactly the same number of parameters, about 296 thousand, which makes them a fair pair to compare.
